판정 기준 (이 실행에 쓰인 값)

  • 폭 사다리 = CSS 미디어쿼리·컨테이너 max-width 실측(480, 500, 768) + 경계 직전(B−1) + 구간 중점 + 표준 기기폭(360·390·768·1024·1440). 중점이 핵심 — 260805 결함은 480↔768 구간 한가운데(600px대)에 있었고 경계만 봤으면 못 잡는다.
  • 가로 오버플로 = scrollWidth − clientWidth > 0. 하드 판정(종료코드 1).
  • 세로 경계선 검출 = 인접 열 휘도차 > 6(0~255)가 세로 64px 창 안 90% 이상 행에서 같은 방향으로 발생. 방향 일치 조건이 글자·필름그레인을 걸러낸다. 좌우 가장자리 2px 무시.
  • 단차 / 얇은 선 분류 = 검출된 경계선 좌우로 3px 띄운 7px 영역의 평균 휘도차가 8 이상이면 단차(step · 주목), 미만이면 얇은 선(line · 정상 경계). 결함은 한쪽 영역이 통째로 어두워지는 단차로 나타나고, 카드 테두리·아이콘은 양옆이 같은 얇은 선이다.
  • 이미지 내부 제외 = img·svg·canvas·video 사각형 내부의 세로 경계선은 그림 내용물이라 판정에서 뺀다(QR 코드 하나가 Δ150+ 단차를 십수 개 낸다). 바깥 테두리는 그대로 본다. 배경 셰이더 #wavebg는 화면 전체라 제외 대상에서 뺀다.
  • 측정 조건 = DPR 1(1px = 1 CSS px) · 스크롤바 숨김 · 첫 페인트 후 1.2s 대기 · 캡처 상단 720px.
